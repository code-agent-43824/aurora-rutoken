# Релиз v1.3

Аннотированный тег `v1.3` указывает на коммит `ce1277e`; версия приложения —
`1.3.0-23`. Функциональные сценарии подтверждены владельцем на физическом
armv7hl-телефоне с Авророй 5.2 и установленным КриптоПро CSP. Финальный код
собран и проверен GitHub Actions run `31384149912`: обе архитектуры,
официальный RPM validator и атомарная публикация четырёх RPM.

## Что добавлено

- создание контейнера КриптоПро и неэкспортируемой ключевой пары ГОСТ
  Р 34.10-2012/256 или /512 на выбранном Рутокене;
- одинаковый сценарий по USB и NFC; NFC выполняет запись и перечитывание за
  одно поднесение;
- отдельный одноразовый helper-процесс записи: сбой CSP не завершает UI, а
  PIN-код передаётся только через stdin и не попадает в аргументы процесса;
- безопасный откат только что созданного контейнера, если генерация ключевой
  пары не завершилась;
- технический путь формирования и подписи PKCS#10 средствами самого CSP,
  проверенный внешним ГОСТ-инструментом;
- единый канонический алгоритм представления объектов PKCS#11 и КриптоПро:
  контейнер режима PKCS#11 сопоставляется с парой по `CKA_ID`, одна физическая
  пара показывается одной карточкой, а источник отмечается явно;
- различение полной ключевой пары и одиночного открытого/закрытого ключа;
- выбор используемых типов ГОСТ-провайдера в настройках и сокращение дорогих
  обращений к носителю.

## Границы выпуска

Пользовательский вход в PKCS#10 через КриптоПро в финальной `1.3.0-23`
выключен: контейнеры, создаваемые приложением на проверенном устройстве,
получаются в режиме PKCS#11 и обслуживаются существующим CSR-путём PKCS#11.
Сам CSP-путь реализован и был успешно проверен на устройстве.

Принудительный выбор режима носителя не включён. Документированный механизм
`PP_CARRIER_TYPES` найден, но числовые значения нужных констант SDK КриптоПро
5.0 отсутствуют в доступных заголовках; подставлять их наугад небезопасно.
Объекты форматов CSP и ФКН, созданные вне приложения, остаются read-only.

## Проверка

На физическом телефоне подтверждены создание контейнера по USB и NFC,
неэкспортируемая ключевая пара, откат при ошибке, PKCS#10 через провайдер,
склейка представлений объектов, подписи «ключевая пара» / «только закрытый
ключ» и очищенный экран создания. Последняя аппаратно проверенная сборка —
`1.3.0-22`; `1.3.0-23` дополнительно не открывает контейнеры режима PKCS#11
при чтении и выключает неиспользуемый вход PKCS#10. Отдельный замер времени
точной `1.3.0-23` ещё не снят; полный CI прошёл без предупреждений компилятора.

## Установка

В GitHub Release `v1.3` опубликованы четыре RPM: приложение и неизменённая
официальная библиотека Рутокен PKCS#11 для `armv7hl` и `aarch64`. На телефоне
в режиме разработчика сначала устанавливается библиотека своей архитектуры,
затем RPM приложения `1.3.0-23`. Для функций v1.2/v1.3 отдельно требуется
лицензированный пакет КриптоПро CSP, совместимый с установленной версией
Авроры. Пакеты приложения подписаны публичным тестовым ключом OMP Regular и
не предназначены для production-публикации.
