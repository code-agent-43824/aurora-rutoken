# v1.0 — первый стабильный выпуск

Приложение для Авроры 5.2+ работает с устройствами Рутокен ЭЦП 3.0 по USB и
NFC через официальный PKCS#11-модуль Рутокен.

## Возможности

- обнаружение устройств и просмотр свойств;
- вход по PIN-коду, просмотр сертификатов и ключей;
- генерация ключей ГОСТ Р 34.10-2012 и RSA;
- импорт и экспорт сертификатов;
- смена PIN-кодов и метки, разблокировка пользовательского PIN;
- удаление объектов;
- создание запросов PKCS#10 (CSR);
- отдельный пошаговый сценарий операций по NFC.

## Установка

Для своей архитектуры сначала установите официальный пакет
`ru.rutoken.librtpkcs11ecp-2.19.0.0-1`, затем пакет приложения
`ru.codeagent43824.rutokentestapp-1.0.0-5`.

В launcher приложение называется «Рутокен». Иконка выполнена как абстрактный
силуэт Рутокен ЭЦП 3.0 NFC Slim-C с разъёмом USB Type-C.

RPM приложения подписаны общедоступным тестовым ключом ОМП Regular и
предназначены для телефона с включённым режимом разработчика.
