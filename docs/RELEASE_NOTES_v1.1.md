# Релиз v1.1

Стабильный тег `v1.1` указывает на кодовую сборку `1.1.0-2` (`800c265`).
Владелец проверил её на физическом armv7hl-телефоне с Авророй 5.2; готовая
CMS-подпись проходит независимую внешнюю проверку.

## Что добавлено

- detached CMS (`.p7s`) и attached CMS (`.p7m`) выбранного файла;
- выбор сертификата, исходного файла, каталога и имени результата;
- USB и NFC через существующие безопасные PIN-потоки;
- программное хеширование файла библиотекой на смартфоне, при этом закрытый
  ключ и операция подписи остаются в Рутокене;
- действующие сертификаты выше просроченных; просроченные приглушены и не
  могут использоваться для подписи ни в UI, ни в backend.

## Установка

В GitHub Release `v1.1` опубликованы четыре RPM: приложение и неизменённая
официальная библиотека Рутокен PKCS#11 для `armv7hl` и `aarch64`. На телефоне
в режиме разработчика сначала устанавливается библиотека своей архитектуры,
затем RPM приложения. Пакеты приложения подписаны публичным тестовым ключом
OMP Regular и не предназначены для production-публикации.
