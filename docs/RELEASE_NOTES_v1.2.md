# Релиз v1.2

Стабильный тег `v1.2` указывает на кодовую сборку `1.2.0-10` (`c19d486`).
Основные сценарии интеграции проверены владельцем на физическом armv7hl-
телефоне с Авророй 5.2 и установленным КриптоПро CSP. Точная сборка
`1.2.0-10` прошла полный GitHub Actions run `30577345678`: обе архитектуры,
официальный RPM validator и публикация четырёх RPM.

## Что добавлено

- выключенная по умолчанию настройка «Использовать КриптоПро CSP»;
- динамическая read-only интеграция с установленным внешним CapiLite без
  включения КриптоПро CSP в пакет приложения;
- изолированный helper-процесс для CAPI-вызовов с таймаутом и пределами ответа:
  сбой либо зависание CSP не завершает интерфейс приложения;
- чтение контейнеров и сертификатов из самих контейнеров по USB и NFC;
- объединение объектов КриптоПро с обычным списком объектов Рутокена;
- точная дедупликация сертификатов по DER с приоритетом PKCS#11;
- связь контейнеров с сертификатами по открытому ключу, чтобы не показывать
  один ключ отдельным самостоятельным объектом;
- честная пометка источника: PKCS#11, КриптоПро CSP либо оба интерфейса;
- диагностика версии CSP и фактически загруженных библиотек;
- блокирующий `C_WaitForSlotEvent` вместо периодического опроса Рутокена.

КриптоПро CSP остаётся опциональной внешней зависимостью. Пока настройка
выключена, его библиотеки не загружаются и helper не запускается. Все функции
PKCS#11, включая CMS-подпись v1.1, продолжают работать без CSP.

## Проверка

Последовательные аппаратные smoke-тесты подтвердили обнаружение контейнеров,
чтение сертификата из контейнера до и после ввода PIN-кода, устранение
дубликатов, работу по NFC и сохранение объектов после отрыва устройства.
Последний аппаратно проверенный RC — `1.2.0-9`; `1.2.0-10` содержит только
исправление отображения фактического источника в шапке сертификата и индикатор
чтения. По прямому поручению владельца отдельный smoke точной сборки
`1.2.0-10` не является блокером стабильного выпуска.

## Установка

В GitHub Release `v1.2` опубликованы четыре RPM: приложение и неизменённая
официальная библиотека Рутокен PKCS#11 для `armv7hl` и `aarch64`. На телефоне
в режиме разработчика сначала устанавливается библиотека своей архитектуры,
затем RPM приложения. Для функций v1.2 отдельно требуется лицензированный
пакет КриптоПро CSP, совместимый с установленной версией Авроры. Пакеты
приложения подписаны публичным тестовым ключом OMP Regular и не предназначены
для production-публикации.
